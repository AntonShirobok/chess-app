# Шахматы с нуля — Telegram Mini App

Приложение-игра в Telegram: обучение с нуля, игра с компьютером, который растёт вместе с тобой, и легендарные партии чемпионов.

## Что внутри

- **🎓 Учиться** — 16 уроков с нуля: доска и названия клеток, как ходит каждая фигура (собираешь звёздочки), шах, мат, пат, рокировка, взятие на проходе, ценность фигур, как начинать партию, детский мат, вилка/связка/линейный удар, мат ферзём и ладьёй.
- **♟ Игра** — партия с компьютером. 12 уровней силы, от «Новичка» (≈250) до «Гроссмейстера» (≈1900).
  В режиме **Авто** у тебя есть рейтинг (начинается с 400). Выигрываешь — рейтинг растёт, и компьютер становится сильнее. Проигрываешь — он немного сбавляет силу.
  Есть подсказка, возврат хода и сдача. С подсказками рейтинг меняется вдвое меньше — так честно.
- **🏛 Легенды** — 16 великих партий (Морфи, Стейниц, Ласкер, Капабланка, Ботвинник, Фишер, Карпов, Каспаров, Deep Blue…) с историей и комментариями. Режим **«Угадай ход»**: играешь за победителя и проверяешь, нашёл бы ты ход чемпиона.

- **👥 С другом** (вкладка «Игра») — партия с другом: создаёшь игру, отправляешь приглашение в любой чат Telegram, друг открывает — и вы играете. Можно закрыть приложение и доиграть позже. Нужна разовая настройка — раздел «Игра с друзьями» ниже.

Прогресс сохраняется в самом Telegram, поэтому он не потеряется при смене телефона.
Сервер не нужен: это обычный сайт на GitHub Pages, как приложение с винилом.

## Как запустить (один раз, ~10 минут)

### Шаг 1. Сайт на GitHub Pages
Это делает Claude: создаёт репозиторий `chess-app` на твоём GitHub и включает Pages.
Адрес будет такой: **https://antonshirobok.github.io/chess-app/**
Открой его в браузере на телефоне — должно открыться приложение.

### Шаг 2. Новый бот
1. В Telegram открой **@BotFather**.
2. Отправь `/newbot`.
3. Имя бота — например `Шахматы с нуля`.
4. Юзернейм — что-нибудь свободное, на конце обязательно `bot`, например `my_chess_school_bot`.

### Шаг 3. Кнопка «Играть» в боте
1. В @BotFather отправь `/mybots` → выбери нового бота.
2. **Bot Settings** → **Menu Button** → **Configure menu button**.
3. Пришли ссылку: `https://antonshirobok.github.io/chess-app/`
4. Пришли название кнопки: `♟ Играть`.

### Шаг 4 (по желанию). Красивый запуск по ссылке
1. В @BotFather: `/newapp` → выбери бота.
2. Название, описание, картинку 640×360 (можно пропустить, отправив `/empty`, где разрешено).
3. Ссылка: `https://antonshirobok.github.io/chess-app/`
4. Короткое имя, например `chess`.
Тогда приложение открывается по ссылке `t.me/имя_бота/chess` — её удобно кидать друзьям.

Готово! Открой бота и нажми **♟ Играть** внизу слева.

## Игра с друзьями (один раз, ~10 минут)

Для игры по сети нужен маленький сервер. Это бесплатный Google Apps Script — то же самое, что ты делал для винила.

### Шаг 1. Таблица и скрипт
1. Открой [sheets.new](https://sheets.new) — создастся новая Google-таблица. Назови её, например, «Шахматы — партии».
2. Вверху: **Расширения → Apps Script**. Откроется редактор кода.
3. Сотри всё, что там написано, и вставь всё содержимое файла `gas/Code.gs` из папки `chess-app`. Нажми 💾.
4. Вверху, рядом с кнопкой «▶ Выполнить», выбери функцию **setup** и нажми **▶ Выполнить**.
   Google попросит доступ: **Проверить разрешения** → свой аккаунт → **Дополнительно** → **Перейти к проекту** → **Разрешить**.
   В таблице появится лист **«Партии»**.

### Шаг 2. Сделать скрипт доступным для приложения
1. Справа вверху: **Начать развертывание → Новое развертывание**.
2. Шестерёнка → **Веб-приложение**.
3. Запуск от имени: **Я**. У кого есть доступ: **Все**.
4. **Начать развертывание** и скопируй **URL веб-приложения** (заканчивается на `/exec`).
5. **Пришли этот URL Claude** — он вставит его в приложение.

### Шаг 3. Ссылки-приглашения (чтобы друг попадал в партию одним нажатием)
1. В @BotFather: `/newapp` → выбери своего бота.
2. Название и описание — любые, картинку можно пропустить.
3. Ссылка: `https://antonshirobok.github.io/chess-app/`
4. Короткое имя, например `chess`.
5. **Пришли Claude юзернейм бота и это короткое имя.**

Без шага 3 тоже можно играть: приложение покажет **код партии** (например `K7QM2X`), друг вводит его во вкладке «Игра» → «С другом».

### Как играть
«Игра» → **👥 С другом** → выбери цвет → **Создать партию и позвать** → **Отправить приглашение** → выбери чат с другом.
Ход соперника появляется через 1–2 секунды. Все партии видны в таблице, в листе «Партии».

## Если что-то не так

- **Белый экран** — подожди 1–2 минуты после публикации (GitHub Pages обновляется не сразу) и открой заново.
- **Обновил приложение, а в Telegram старая версия** — закрой мини-приложение полностью и открой снова; иногда помогает потянуть экран вниз.
- **Хочу начать прогресс заново** — пока только переустановкой данных: напиши Claude, добавим кнопку «Сбросить».

## Файлы (для себя)
- `index.html`, `styles.css`, `app.js` — само приложение
- `engine.js` — шахматный движок (компьютер)
- `ai.js` — уровни силы компьютера
- `data/lessons.js` — уроки (можно дописывать новые)
- `data/games.js` — легендарные партии (можно добавлять свои)
- `online.js`, `config.js` — игра с друзьями и её настройки
- `gas/Code.gs` — сервер для игры с друзьями (вставляется в Google-таблицу)
- `lib/chess.js` — правила шахмат (библиотека chess.js, BSD)
- `pieces/` — фигуры (набор cburnett с lichess, GPL)
